# Open Neuron

An educational Python library for understanding fully connected neural networks.

The project will implement the computations explicitly with NumPy so the forward pass, loss, backpropagation, and parameter updates remain inspectable. It is a learning project, not a replacement for Keras or TensorFlow.

The implementation is being migrated incrementally from the workspace's legacy `openneuron/` sources. The first package scaffold is intentionally empty while the existing code is reviewed.

The project and import package are both named `open_neuron`.

## Development install

From this directory, install the package in editable mode:

```sh
python -m pip install -e .
```
